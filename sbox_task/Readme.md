# Задание 1 - Comb
## Постановка задачи:

1. Выбрать произвольные 4-битные подстановку (S-box) и перестановку P.
2. Представить оба в табличном виде (в какое выходное значение отображается каждое входное значение). Тривиальные (тождественные) преобразования не принимаются!
3. Описать на SystemVerilog модуль с двумя 4-битными входами data и key, реализующий композицию отображений XPS, где на data сначала действует S, затем P, и в конце X - побитовое исключающее ИЛИ (XOR) с key.
4. Записать таблицу для композиции отображений PS.
5. Написать тестбенч для модуля, используя таблицу из 4.
6. Тестбенч должен перебирать все возможные значения входов и выводить сообщение в случае ошибки!
7. Запустить симуляцию и убедиться, что получившийся модуль работает правильно.
8. Создать проект в Gowin EDA, добавить в него файл(ы) с описанием модуля(ей) (из 2.)
9. Выполнить синтез, посмотреть схематику, посмотреть затраченные ресурсы (LUT)
